## 一、Docker 部署

服务器 Linux 环境下使用 `docker-compose-deploy.yml`：

```bash
# 1. 安装 docker-compose（如未安装）
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 2. 启动
docker-compose -f docker-compose-deploy.yml up -d
```

- Web 端口：`9988`（宿主机 9988 → 容器 9988）
- MariaDB 端口：`3306`（宿主机 3306 → 容器 3306）
- 数据库：用户 `root` / 密码 `root` / 库名 `instock`

访问：`http://<服务器IP>:9988/`

首次启动要点：
- `cn_stock_attention` 等基础表需要初始化（见"常见问题"）。
- 数据抓取任务首次运行需 10-30 分钟，表由任务执行后才创建。

## 二、本地（Windows）启动

依赖安装：

```bat
cd stock
pip install -r requirements.txt
```

启动 Web 服务（双击或命令行）：

```bat
cd instock\bin
run_web.bat
```

访问：`http://localhost:9988/`

启动数据任务：

```bat
cd instock\job
python execute_daily_job.py     :: 全量任务
python basic_data_daily_job.py  :: 仅盘中实时行情
```

## 三、数据库连接配置

连接参数在 `instock/lib/database.py` 顶部（默认值，可用环境变量覆盖）：

| 参数 | 默认值 | 环境变量 |
|------|--------|----------|
| 主机 | `192.168.201.62` | `db_host` |
| 端口 | `3306` | `db_port` |
| 用户 | `root` | `db_user` |
| 密码 | `root` | `db_password` |
| 库名 | `instock` | `db_database` |

Docker 部署时通过 compose 的 `environment` 传入这些环境变量。

## 四、各功能启动顺序

依赖关系：**行情 → 指标/形态 → 策略 → 回测**。

### 第一阶段：初始化（只需一次）

```bash
python instock/job/init_job.py            # 建库、建基础表
python instock/job/create_all_tables.py   # 一次性补齐所有 web 数据表
```

### 第二阶段：基础行情（所有后续任务的前提）

```bash
python instock/job/basic_data_daily_job.py   # 股票/ETF 实时快照
```

### 第三阶段：独立数据（不依赖历史行情）

```bash
python instock/job/basic_data_other_daily_job.py     # 龙虎榜/分红/资金流向/早盘抢筹/涨停原因
python instock/job/basic_data_after_close_daily_job.py # 大宗交易/尾盘抢筹（收盘后）
python instock/job/selection_data_daily_job.py         # 综合选股
```

### 第四阶段：重计算任务（收盘后执行，耗时较长）

```bash
python instock/job/indicators_data_daily_job.py    # 技术指标（依赖第二阶段）
python instock/job/klinepattern_data_daily_job.py  # K线形态
python instock/job/strategy_data_daily_job.py      # 交易策略
python instock/job/backtest_data_daily_job.py      # 回测收益率（依赖上面的结果）
```

### 一键全量执行

`instock/job/execute_daily_job.py` 已解锁全部任务，按上述依赖顺序执行：

```bash
python instock/job/execute_daily_job.py
```

## 五、近实时数据操作

盘中时段（9:00-15:00）重复运行基础行情任务即可保持近实时，建议每 30 分钟一次：

```bash
python instock/job/basic_data_daily_job.py 2026-09-22
```

支持批量日期：

```bash
python instock/job/basic_data_daily_job.py 2026-09-21,2026-09-22   # N 个日期
python instock/job/basic_data_daily_job.py 2026-09-21 2026-09-25   # 区间
```

Docker 环境下系统自带 cron：每小时盘中自动跑基础行情，17:30 跑全量任务。

## 六、常见问题排查

### 1. 接口报 `Table 'xxx' doesn't exist`

表由任务成功写入时才创建。执行初始化或对应数据任务：

```bash
python instock/job/init_job.py
python instock/job/create_all_tables.py
```

### 2. 网页有表但无数据（返回 `[]`）

- 检查日期是否为交易日，且任务已执行；
- 查看任务日志：`instock/log/stock_execute_job.log`；
- 若抓取失败，多为东财接口限流/缺 cookie，检查 `instock/config/eastmoney_cookie.txt`。

### 3. Docker 内没有 mysql 客户端

MariaDB 新版镜像用 `mariadb` 命令代替：

```bash
docker exec -it InStockDbService mariadb -uroot -proot instock -e "SHOW TABLES;"
```

### 4. 日志位置

- Web：`instock/log/stock_web.log`
- 数据任务：`instock/log/stock_execute_job.log`
- 历史行情缓存：`instock/cache/hist/`
