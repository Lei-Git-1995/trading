## 📊 核心功能清单

### 1. v1 架构（生产级）

**9个预设策略**：
- ✅ default - 默认策略
- ✅ aggressive - 激进策略（追涨）
- ✅ conservative - 保守策略（稳健）
- ✅ dip_buying - 低吸策略
- ✅ breakout - 突破策略
- ✅ mainboard_only - 只选主板
- ✅ sector_rotation - 题材轮动
- ✅ value_return - 价值回归
- ✅ limit_up_chase - 打板策略

**核心能力**：
- 换手率、涨跌幅、量比筛选
- KDJ、RSI 技术指标过滤
- 外盘内盘资金流向判断
- 板块数量限制
- 综合评分排序

### 2. v2 架构（技术就绪）

**3个新策略**：
- ✅ ultra_short - 超短线启动策略
- ✅ momentum_start - 启动策略
- ✅ weak_to_strong - 弱转强策略

**核心特性**：
- 100分制多维度评分
- filters/signals/risk 三段式
- 10+ 高级指标
- 风险控制机制

**当前限制**：
- 依赖板块数据（接口不稳定）
- 依赖资金流向（接口不稳定）
- 需要更好的数据源支持

### 3. 智能数据源系统

**健康监控**：
- 自动测试所有数据源
- 记录成功率、响应时间
- 生成健康报告

**自动切换**：
- 优先使用成功率最高的数据源
- 失败时自动切换备用
- 容灾保障

**当前状态**：

- ❌ AkShare：失败

### 4. 高级指标库

## 📝 使用指南

### 快速开始

```bash
# 1. 进入项目目录
cd E:\trading

# 2. 运行选股（保守策略）
py -3.11 -m stock_selector.main --preset conservative

# 3. 查看报告
cat stock_selector/output/2026-09-24.md
```

### 常用命令

```bash
# 查看所有预设策略
py -3.11 -m stock_selector.main --list-presets

# 使用不同策略
py -3.11 -m stock_selector.main --preset aggressive
py -3.11 -m stock_selector.main --preset dip_buying

# 自定义参数
py -3.11 -m stock_selector.main --turnover 10 --change 1,5 --volume 1.5

# 数据源健康检测
py -3.11 -m stock_selector.data.provider_health_monitor

py -3.11 -m stock_selector.main --help
```

## ⚠️ 已知问题与限制

### 1. v2 策略数据源问题

**问题**：板块数据和资金流向接口不稳定

**影响**：v2 策略无法正常筛选股票（0只通过）

**临时方案**：使用 v1 策略

**长期方案**：
- 寻找稳定的付费数据源
- 或调整 v2 策略配置

### 2. 东方财富数据源不可用

**问题**：所有主机不可达

**影响**：无法使用东方财富作为数据源

**方案**：自动切换到腾讯数据源

### 常见问题

**Q: 为什么没有选出股票？**
A: 可能是当天市场不符合策略条件，尝试更宽松的策略（conservative）或自定义参数。

**Q: 数据源失败怎么办？**
A: 系统会自动切换，无需手动干预。可运行健康检测查看状态。

**Q: 如何添加自定义策略？**
A: 编辑 `presets.yaml` 或 `presets_v2.yaml`，参考现有策略格式。

**Q: v2 策略为什么不工作？**
A: v2 依赖板块数据和资金流向，当前数据源不稳定。建议使用 v1 或等待数据源改善。
