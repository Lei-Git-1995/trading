## 基础命令

```bash
cd E:\trading

```
**说明**：使用默认配置（换手>15%，涨幅1-3%，量能>1.5倍）进行选股

```bash
py -3.11 -m stock_selector.main --help
```

## 预设策略

### 1. 默认策略（适中标准）
```bash
py -3.11 -m stock_selector.main --preset default
```
- **换手率**：> 15%
- **涨跌幅**：1% ~ 3%
- **量能**：> 1.5倍
- **适用场景**：日常选股，平衡风险和收益

### 2. 激进策略（捕捉强势股）
```bash
py -3.11 -m stock_selector.main --preset aggressive
```
- **换手率**：> 20%
- **涨跌幅**：3% ~ 7%
- **量能**：> 2.5倍
- **适用场景**：追涨强势股，短线操作

### 3. 保守策略（稳健标的）
```bash
py -3.11 -m stock_selector.main --preset conservative
```
- **换手率**：> 8%
- **涨跌幅**：0% ~ 3%
- **量能**：> 1.2倍
- **特点**：过滤创业板和科创板
- **适用场景**：稳健投资，风险厌恶型

### 4. 低吸策略（寻找反弹机会）
```bash
py -3.11 -m stock_selector.main --preset dip_buying
```
- **换手率**：> 12%
- **涨跌幅**：-2% ~ 2%
- **量能**：> 1.8倍
- **适用场景**：低位买入，等待反弹

### 5. 突破策略（放量突破）
```bash
py -3.11 -m stock_selector.main --preset breakout
```
- **换手率**：> 18%
- **涨跌幅**：2% ~ 5%
- **量能**：> 3.0倍
- **特点**：不限制KDJ和RSI超买
- **适用场景**：捕捉突破行情

### 6. 主板策略（只选主板股）
```bash
py -3.11 -m stock_selector.main --preset mainboard_only
```
- **换手率**：> 12%
- **涨跌幅**：1% ~ 4%
- **量能**：> 1.5倍
- **特点**：只选主板，过滤创业板和科创板
- **适用场景**：偏好大盘蓝筹股

## 自定义参数

### 设置换手率
```bash
# 换手率 > 10%
py -3.11 -m stock_selector.main --turnover 10

# 换手率 > 20%（高活跃度）
py -3.11 -m stock_selector.main --turnover 20
```
**说明**：换手率越高，表示股票交易越活跃

### 设置涨跌幅区间
```bash
# 涨幅 1% ~ 5%
py -3.11 -m stock_selector.main --change 1,5

# 涨幅 0% ~ 3%（温和上涨）
py -3.11 -m stock_selector.main --change 0,3

# 允许下跌：-2% ~ 2%（低吸策略）
py -3.11 -m stock_selector.main --change -2,2

# 大涨：5% ~ 9%（追强势）
py -3.11 -m stock_selector.main --change 5,9
```
**说明**：格式为 `最小值,最大值`，支持负数

### 设置量能倍数
```bash
# 量能放大 1.5 倍
py -3.11 -m stock_selector.main --volume 1.5

# 量能放大 2.5 倍（强放量）
py -3.11 -m stock_selector.main --volume 2.5

# 量能放大 1.2 倍（温和放量）
py -3.11 -m stock_selector.main --volume 1.2
```
**说明**：相对于前两日平均成交量的放大倍数

### 设置板块限制
```bash
# 每个板块最多选 10 只
py -3.11 -m stock_selector.main --sector 10

# 每个板块最多选 30 只
py -3.11 -m stock_selector.main --sector 30

# 不限制板块数量
py -3.11 -m stock_selector.main --sector 0
```
**说明**：避免某个板块过度集中

### 组合使用多个参数
```bash
# 自定义组合
py -3.11 -m stock_selector.main --turnover 12 --change 1,5 --volume 1.8 --sector 15
```

## 筛选条件

### 只选主板股票（过滤创业板和科创板）
```bash
py -3.11 -m stock_selector.main --mainboard-only
```
**说明**：自动过滤代码以3开头的创业板和688开头的科创板

### 过滤创业板
```bash
py -3.11 -m stock_selector.main --no-cyb
```
**说明**：过滤代码以3开头的创业板股票

### 过滤科创板
```bash
py -3.11 -m stock_selector.main --no-kcb
```
**说明**：过滤代码以688开头的科创板股票

### 不检查外盘内盘关系
```bash
py -3.11 -m stock_selector.main --no-outer
```
**说明**：默认要求外盘>内盘（主动买入>主动卖出），此参数禁用该检查

### 不检查KDJ超买
```bash
py -3.11 -m stock_selector.main --no-kdj
```
**说明**：默认要求KDJ_K < 80（未超买），此参数禁用该检查

### 不检查RSI超买
```bash
py -3.11 -m stock_selector.main --no-rsi
```
**说明**：默认要求RSI6 < 70（未超买），此参数禁用该检查

### 组合筛选条件
```bash
# 主板股票 + 不检查超买指标
py -3.11 -m stock_selector.main --mainboard-only --no-kdj --no-rsi

# 过滤创业板 + 不检查外盘内盘
py -3.11 -m stock_selector.main --no-cyb --no-outer
```

## 高级用法

### 交互式输入参数
```bash
py -3.11 -m stock_selector.main -i
```
**说明**：程序会逐个提示输入参数，直接回车使用默认值

### 不使用缓存（强制重新拉取数据）
```bash
py -3.11 -m stock_selector.main --no-cache
```
**说明**：忽略本地缓存的K线数据，确保使用最新数据

### 预设策略 + 自定义参数覆盖
```bash
# 使用激进策略，但降低量能要求
py -3.11 -m stock_selector.main --preset aggressive --volume 2.0

# 使用保守策略，但调整涨幅区间
py -3.11 -m stock_selector.main --preset conservative --change 0,2 --turnover 10

# 使用默认策略，但只选主板
py -3.11 -m stock_selector.main --preset default --mainboard-only
```
**说明**：命令行参数会覆盖预设中的对应值

### 完整自定义配置
```bash
py -3.11 -m stock_selector.main \
  --turnover 15 \
  --change 2,5 \
  --volume 2.0 \
  --sector 20 \
  --mainboard-only \
  --no-kdj \
  --source eastmoney \
  --log-level INFO \
  --no-cache
```


```bash
py -3.11 -m stock_selector.main --turnover 10 --change 1,4 --volume 1.3 --mainboard-only
```

```bash
py -3.11 -m stock_selector.main --preset aggressive --mainboard-only
```

## 常见问题

### Q1: 如何每天快速选股？
**A**: 使用预设策略最方便，推荐：
```bash
py -3.11 -m stock_selector.main --preset default
```

### Q2: 如何只看主板股票？
**A**: 使用 `--mainboard-only` 参数：
```bash
py -3.11 -m stock_selector.main --mainboard-only
```

### Q3: 如何调整参数找到更多股票？
**A**: 降低筛选条件：
```bash
# 降低换手率和量能要求
py -3.11 -m stock_selector.main --turnover 8 --volume 1.2
```

### Q4: 如何找到更少但更精准的股票？
**A**: 提高筛选条件：
```bash
# 提高换手率和量能要求
py -3.11 -m stock_selector.main --turnover 25 --volume 3.0
```

### Q5: 报告文件在哪里？
**A**: 在 `stock_selector/output/YYYY-MM-DD.md`

### Q6: 如何保存自己的常用参数？
**A**: 编辑 `presets.yaml` 文件，添加自己的预设策略
