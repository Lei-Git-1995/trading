# stock_selector — 每日短线选股系统

抓取全市场 A 股实时行情（**多数据源可选：东方财富 / 腾讯 / 新浪(akshare)**，运行时可交互切换），按短线条件筛选、技术指标验证、综合评分排序，最终生成 **Markdown 选股报告**。

---

## 1. 整体架构

```
stock_selector/
├── config.py                       # 配置：筛选参数 + 目录路径
├── main.py                         # 程序入口，CLI 参数，串联全流程
├── data/                           # 数据层
│   ├── eastmoney_client.py         # 东方财富行情客户端（实时快照 / 个股K线，多主机容灾）
│   ├── stock_list.py               # 快照整理：字段归一化、过滤ST、计算内外盘占比
│   ├── cache.py                    # K线本地缓存（pickle + TTL，按数据源分目录隔离）
│   └── providers/                  # 多数据源适配层（工厂 + 注册 + 交互选择）
│       ├── base.py                 # 抽象基类/字段定义/注册表/工厂/重试
│       ├── eastmoney_provider.py   # 数据源1：东方财富（K线不可达回退腾讯）
│       ├── tencent_provider.py     # 数据源2：腾讯（经 akshare，含换手/量比）
│       └── akshare_provider.py     # 数据源3：新浪（经 akshare，缺换手/外盘）
├── indicators/                     # 技术指标
│   ├── kdj.py                      # KDJ 随机指标
│   ├── rsi.py                      # RSI 相对强弱
│   └── volume.py                   # 量能放量倍数
├── strategies/
│   └── short_term_selector.py      # 短选策略：快筛→深度分析→评分→板块限制
├── reports/
│   ├── markdown_report.py          # Markdown 报告（模板驱动，当前默认输出）
│   └── excel_report.py             # Excel 报告（可选保留）
└── output/                         # 报告输出目录（YYYY-MM-DD.md）
```

**分层职责：**

| 层 | 模块 | 职责 |
|----|------|------|
| 配置 | `config.py` | 集中管理所有筛选阈值与路径，主程序只认这一份配置 |
| 数据 | `data/` | 负责"数据从哪来、怎么整理、怎么缓存"，不参与任何选股逻辑 |
| 指标 | `indicators/` | 纯函数，输入行情输出指标值，可独立测试 |
| 策略 | `strategies/` | 组合数据与指标，实现选股规则与评分 |
| 报告 | `reports/` | 把结果渲染成 Markdown（或 Excel）报告，无业务逻辑 |

## 2. 各文件职责详解

### 2.1 `config.py`
程序全局配置。定义 `ScreenerConfig`（dataclass）存放筛选参数：

- `turnover_min=15` — 最低换手率（%）
- `change_min=1 / change_max=3` — 涨跌幅区间（%）
- `volume_ratio=1.5` — 量能放大倍数（相对前两日平均）
- `top_per_sector=20` — 每个板块最多入选数量（0 表示不限制）
- `history_days=10` — 个股历史K线取几天（取10天保证腾讯回退通道滞后1日时仍能带出当日数据）
- `request_sleep=0.3` — 历史数据请求间隔（防限流）
- `cache_ttl_hours=8` — K线缓存有效期
- `check_outer_inner=True` — 是否要求外盘>内盘（`--no-outer` 关闭）
- `check_kdj=True` — 是否要求 KDJ 未超买（`--no-kdj` 关闭）
- `check_rsi=True` — 是否要求 RSI 未超买（`--no-rsi` 关闭）
- `filter_cyb=False` — 是否过滤创业板，3开头（`--no-cyb` 开启）
- `filter_kcb=False` — 是否过滤科创板，688开头（`--no-kcb` 开启）

并定义输出目录 `output/`、缓存目录 `data/.cache`（按脚本所在位置自动定位，路径随处可运行）。入口用 `build_config(**kwargs)` 用命令行参数覆盖默认值。

### 2.2 `main.py`
程序入口，负责：

1. 解析命令行参数（`--turnover/--change/--volume/--sector/--no-outer/--no-kdj/--no-rsi/--no-cyb/--no-kcb/--no-cache/--source`）
2. 数据源选择：`--source eastmoney|tencent|akshare` 直接指定；不指定则**交互式弹出菜单选择**（回车默认东方财富）
3. 通过 `providers.create_provider()` 创建数据源适配器，`get_all_stocks()` 拉全市场快照
4. 交给 `ShortTermSelector.run()` 完成筛选 → 评分 → 板块限制
5. 交给 `reports/markdown_report.generate()` 生成 `output/YYYY-MM-DD.md`
6. 打印 Top5 摘要

启动方式（在 `E:\trading` 目录下）：

```
py -3.11 -m stock_selector.main --turnover 10 --change 1,5 --volume 0.8 --no-outer
py -3.11 -m stock_selector.main --source tencent          # 指定腾讯数据源
```

### 2.3 多数据源（`data/providers/`）

所有数据源实现统一接口 `DataProvider`，输出**相同字段**，策略与报告层无需感知数据源差异：

| 数据源 | 入口列表 | 日K线 | 换手率 | 量比 | 外盘/内盘 | 行业板块 | 速度(约) |
|--------|----------|-------|--------|------|-----------|----------|----------|
| 东方财富(默认) | 直连 clist | push2his（不可达自动回退腾讯） | ✅ | ✅ | ✅ | ✅ | 4s |
| 腾讯 | `stock_zh_a_spot_tx` | `stock_zh_a_hist_tx` | ✅ | ✅ | ❌ | ❌(按代码段推断) | 8s |
| 新浪(akshare) | `stock_zh_a_spot` | `stock_zh_a_daily` | ❌(自动跳过换手过滤) | ❌ | ❌ | ❌(按代码段推断) | 18s |

缺失字段的处理：
- **缺换手/量比**：自动跳过对应的筛选条件，报告对应项显示 `-`
- **缺外盘/内盘**：自动跳过"外盘>内盘"检查，报告资金流向显示"数据源未提供"
- **接口报错**：自动重试 3 次（间隔5秒），仍失败则提示并退出，不中断崩溃

### 2.4 `data/eastmoney_client.py`
东方财富行情客户端，封装两个公开接口：

- **`get_all_stocks()`** — 调用 `82.push2.eastmoney.com` 分页拉取沪深 A 股实时行情快照，返回包含代码/名称/最新价/涨跌幅/换手率/成交量/内盘/外盘/板块等原始字段的 DataFrame（每页1000只，自动翻页直到取完）。
- **`get_stock_history(code, days=5)`** — 调用 `push2his.eastmoney.com` 获取个股近 N 日 K 线，返回标准化日 K 数据（日期/开盘/收盘/最高/最低/成交量/成交额/振幅/涨跌幅/涨跌额/换手率）。

模块内部统一走 `requests.Session`，带超时与重试保护。

### 2.5 `data/stock_list.py`
快照整理函数 `load_stock_list(raw)` 职责：

- 字段归一化（价格分→元，涨跌幅/换手率万分位→百分比）
- **过滤**名称含 ST、退、`*` 的股票
- 计算**外盘/内盘占比**（`outer_ratio`/`inner_ratio`）
- 板块空值填"未分类"
- 返回标准列：[code, name, price, change_pct, turnover, volume, inner_vol, outer_vol, outer_ratio, inner_ratio, sector]

它把「东方财富的原始 JSON 格式」转换成「策略层统一字段」，是数据层与策略层的解耦点。

### 2.6 `data/cache.py`
K线本地缓存类 `KlineCache`：

- 以 `数据源/股票代码.pkl` 存到 `data/.cache/`（**按数据源分目录隔离**，切换数据源不会串用缓存）
- **进程内字典 + pickle 磁盘双缓存**，带有效期（默认 8 小时）
- 同一天重复运行（或中途失败重跑）时命中缓存，不重复请求逐股 K 线，大幅提速并降低被限流风险
- `clear()` 一键清空缓存

### 2.7 `indicators/kdj.py`
KDJ 随机指标。`kdj(high, low, close, period=9)` 返回 `{'K':…, 'D':…, 'J':…}` 三个 Series，另提供 `kdj_k()` 便捷函数。窗口不足时按实际长度自适应（与原脚本算法一致）。

### 2.8 `indicators/rsi.py`
RSI 相对强弱指标。`rsi(close, period=6)` 标准计算，`rsi6()` 为短线默认周期便捷函数。

### 2.9 `indicators/volume.py`
量能指标：

- `prev_avg_volume(volumes, lookback=2)` — 前 N 日均量
- `volume_ratio(volumes)` — 最新日成交量 / 前两日均量（放量倍数）
- `check_volume_boost(volumes, threshold)` — 返回 `(倍数, 是否满足阈值)`

### 2.10 `strategies/short_term_selector.py`
核心策略 `ShortTermSelector`，四步流程：

| 步骤 | 方法 | 说明 |
|------|------|------|
| 快筛 | `quick_screen()` | 涨跌幅区间、换手率门槛、成交量>0、外盘>内盘 |
| 深度分析 | `deep_analysis()` | 逐股拉K线（走缓存），计算 KDJ/RSI，验证放量倍数，剔除超买（KDJ_K≥80、RSI6≥70） |
| 评分 | `rank()` | 满分80：涨幅10 + 换手10 + 量能15 + 外盘占比15 + KDJ10 + RSI10 + 近3日涨幅10 |
| 板块限制 | `limit_by_sector()` | 每板块最多 N 只（`top_per_sector`），按分数截取后重排 |

`run(stock_list)` 串联以上四步，返回最终结果列表（每项含代码/名称/价格/涨跌幅/换手率/内外盘/量比/KDJ/RSI/近3日涨幅/评分/近5日走势数据）。

### 2.11 `reports/markdown_report.py`
Markdown 报告（当前默认输出）。文件顶部定义了完整报告模板 `REPORT_TEMPLATE`（占位符：`{data_date}` `{generate_time}` `{total_count}` `{conditions}` `{result}` `{footer_time}` `{source}`），由 `render_report()` 填充渲染，`generate()` 写入 `output/YYYY-MM-DD.md`。

报告结构：
- **头部**：行情数据日期、生成时间、筛选数量
- **筛选条件**：本次运行使用的全部条件
- **推荐列表**：Top20 表格（排名/代码/名称/板块/最新价/涨幅/换手/量比/外盘%/评分）
- **Top5 详细分析**：基本信息、技术指标（KDJ/RSI/近3日涨幅）、近5日走势表、选股理由
- **完整候选列表**：股票数>20 时追加
- **风险提示 / 操作建议**

无符合条件股票时，`result` 占位会替换为"暂无符合条件"提示块。

> 附：`reports/excel_report.py` 为早期 Excel 版本（openpyxl），已不再被 `main.py` 调用，如需可单独使用。

## 3. 完整数据流程

```
东方财富实时快照 ── eastmoney_client.get_all_stocks()
        │
        ▼
stock_list.load_stock_list()  过滤ST/退市，计算内外盘占比
        │
        ▼
short_term_selector.run()
   ├─ 快筛：涨跌幅 / 换手率 / 外盘>内盘
   ├─ 深度分析：get_stock_history(缓存) → KDJ / RSI / 放量验证
   ├─ 综合评分（满分80）
   └─ 板块数量限制
        │
        ▼
markdown_report.generate() → output/2026-09-12.md
```

## 4. 使用方法

### 4.1 环境准备

```
py -3.11 -m pip install requests pandas numpy openpyxl
```

### 4.2 运行

两种方式任选（推荐方式1）：

> 方式1：在 `E:\trading` 目录下运行
> 方式2：进入包目录后直接 `py -3.11 main.py`（无需切换目录）

```bash
# —— 方式1：在 E:\trading 目录下 ——
# 默认参数（换手>15%、涨幅1~3%、量能>1.5倍）
py -3.11 -m stock_selector.main

# 自定义换手率
py -3.11 -m stock_selector.main --turnover 10

# 自定义涨跌幅区间（支持负数，寻找超跌反弹）
py -3.11 -m stock_selector.main --change -2,2

# 组合使用
py -3.11 -m stock_selector.main --turnover 20 --change 2,5 --volume 2.5 --sector 10

# 交互式手动输入参数（逐项提示，直接回车使用默认值）
py -3.11 -m stock_selector.main -i

# 放宽条件示例（换手>8%、涨幅0~5%、量能>1.0倍）
py -3.11 -m stock_selector.main --turnover 8 --change 0,5 --volume 1.0

# 不使用缓存，强制重新拉取K线
py -3.11 -m stock_selector.main --no-cache

# 不过滤外盘大于内盘的
py -3.11 -m stock_selector.main --turnover 10 --change 1,5 --volume 0.8 --no-outer

# 组合使用 + 过滤创业板/科创板
py -3.11 -m stock_selector.main --turnover 10 --change 1,5 --volume 0.8 --no-outer --no-cyb --no-kcb

# —— 方式2：已经进入 stock_selector 目录 ——
cd E:\trading\stock_selector
py -3.11 main.py
py -3.11 main.py -i
```

筛选结果较少时，可参考当天行情分布放宽参数（9/12 运行实测）：

| 参数组合 | 初筛数量 |
|----------|----------|
| 换手>15% + 涨幅1~3%（默认） | 3 |
| 换手>15% + 涨幅0~5% | 6 |
| 换手>10% + 涨幅1~3% | 6 |
| 换手>8% + 涨幅1~3% | 8 |
| 换手>8% + 涨幅0~5% + 量能>1.0 | 15 |

### 4.3 命令行参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `--turnover` | 15 | 最低换手率门槛（%） |
| `--change` | "1,3" | 涨跌幅区间，格式 `最小值,最大值`，支持负数 |
| `--volume` | 1.5 | 量能放大倍数（相对前两日平均） |
| `--sector` | 20 | 每板块最多选取数量，0 表示不限制 |
| `--no-outer` | 关 | 不检查外盘内盘关系（默认要求外盘>内盘） |
| `--no-kdj` | 关 | 不检查 KDJ 超买（默认要求 K<80） |
| `--no-rsi` | 关 | 不检查 RSI 超买（默认要求 RSI6<70） |
| `--no-cyb` | 关 | 过滤创业板（3开头） |
| `--no-kcb` | 关 | 过滤科创板（688开头） |
| `-i, --interactive` | - | 交互式手动输入筛选参数，逐项提示，直接回车用默认值 |
| `--no-cache` | - | 禁用 K 线缓存，强制重新拉取 |
| `--source` | 交互选择 | 数据源：`eastmoney`(默认) / `tencent` / `akshare`，不指定则弹出菜单 |

### 4.4 输出

报告生成在 **`stock_selector/output/YYYY-MM-DD.md`**（以运行当天日期命名，如 `2026-09-12.md`），控制台同步打印 Top5 摘要。

## 5. 选股规则速查

| 条件 | 默认 | 说明 |
|------|------|------|
| 换手率 | > 15% | 市场活跃度 |
| 涨跌幅 | 1% ~ 3% | 温和上涨，避免追高也不抄底 |
| 量能 | > 前两日均量 1.5 倍 | 明显放量，资金关注 |
| 外盘 | > 内盘 | 主动买入 > 主动卖出，资金净流入 |
| KDJ_K | < 80 | 不超买 |
| RSI6 | < 70 | 不超买 |
| ST/退市 | 剔除 | 名称含 ST/退/* 一律排除 |
| 板块 | 最多 20 只/板块 | 防止单一板块扎堆 |

## 6. 注意事项

- **数据为盘中实时快照**：脚本建议在盘中（如 14:50 尾盘观察）运行，结果按实时行情给出。若在收盘后运行，腾讯/新浪K线当日 bar 可能滞后，建议用 `history_days=10`（默认已是 10）。
- **K 线缓存有效期 8 小时**：同一天内重复运行不会重复拉取个股 K 线；跨日会自动失效。`--no-cache` 可强制刷新。缓存放 `data/.cache/<数据源名>/`，各数据源互不串用。
- **接口限流**：深度分析逐股请求前有 `0.3s` 间隔，配合缓存，候选股不多时很快。
- **接口可用性 & 容灾**：东方财富行情列表按 `82.push2 → push2 → push2delay` 顺序自动切换可用主机（未知镜像会自动降级为 100 条/页分页）；历史K线东财不可达时自动回退到**腾讯K线**。腾讯/新浪接口偶发限流（做行情源时也内置 3 次重试），若所有通道都不可用，第一步会提示并退出。
- **数据源字段差异**：腾讯/新浪不提供外盘/内盘（自动跳过该检查），新浪不提供换手率/量比（自动跳过换手过滤）。同一天不同数据源选出结果可能不同，属正常现象。
- **仅供学习参考，不构成投资建议。**
