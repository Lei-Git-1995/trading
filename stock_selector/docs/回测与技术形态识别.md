# 回测与技术形态识别

## 历史回测

回测使用本地标准化日线 CSV，不会自动下载全市场历史数据。CSV 必须包含 `开盘`、`收盘`、`最高`、`最低`、`成交量`；推荐同时提供 `日期`、`涨跌幅`。缺少涨跌幅时由指标模块按收盘价计算。日期应升序或可解析排序。

```powershell
cd E:\trading
python -m stock_selector.backtest_runner `
  --input stock_selector\data\history.csv `
  --strategy sideways_then_up_3 `
  --holding-days 1 `
  --fee-rate 0.001 `
  --output stock_selector\output\backtest.md
```

信号在当日收盘后确认，下一交易日开盘入场；`--holding-days 1` 持有至入场当日收盘。手续费按单边比例输入，回测会扣除买卖两边费用。支持 Markdown 报告，输出路径以 `.csv` 结尾时保存逐笔交易 CSV。当前逐笔信号收益按顺序复利统计；当持有期大于 1 天时，信号交易会重叠，因此最大回撤不是资金分配后的组合级回撤。

回测是单股票、单策略的滚动验证。它没有处理涨跌停无法成交、停牌、滑点、复权口径差异、组合资金分配等现实交易约束；结果不能直接视为可实现收益。需要使用足够长、复权一致且无未来数据的历史行情。

## 经典价格形态识别

```python
from stock_selector.indicators.pattern_recognition import detect_pattern, detect_patterns

result = detect_pattern(history_df, 'double_bottom')
all_results = detect_patterns(history_df)
```

目前支持 `double_bottom`（双底）、`double_top`（双顶）、`head_shoulders`（头肩顶）、`triangle`（三角形）和 `rectangle`（矩形整理）。返回值包含是否匹配、说明和几何指标。形态算法只基于价格枢轴做规则识别，尚未经过历史胜率验证，不应单独作为交易信号。

## Excel 与 Webhook

常规选股可用 `--excel` 同时输出 Excel；用 `--excel-output PATH` 可指定文件路径。v2 入口也支持这两个参数。推送通知通过 `--notify-webhook URL` 发送通用文本 JSON，执行环境需能访问该 URL，且机器人可能需要额外签名格式；当前模块不保存密钥。
