# 如何自定义创建策略

## 方法一：编辑 YAML 配置文件（推荐）

### 步骤1：打开配置文件

编辑文件：`E:\trading\stock_selector\presets.yaml`

### 步骤2：添加自定义策略

在文件末尾添加你的策略配置：

```yaml
presets:
  # ... 现有预设 ...

  # 你的自定义策略
  my_strategy:
    turnover: 12.0           # 换手率 > 12%
    change: [1, 4]           # 涨幅 1% ~ 4%
    volume: 1.8              # 量能 > 1.8倍
    sector: 20               # 每板块最多20只
    check_outer_inner: true  # 检查外盘>内盘
    check_kdj: true          # 检查KDJ未超买
    check_rsi: true          # 检查RSI未超买
    filter_cyb: false        # 不过滤创业板
    filter_kcb: false        # 不过滤科创板
    mainboard_only: false    # 不限制只选主板
```

### 步骤3：使用自定义策略

```bash
py -3.11 -m stock_selector.main --preset my_strategy
```

## 方法二：命令行参数组合（临时测试）

不修改配置文件，直接通过命令行参数测试策略：

### 示例1：自定义温和策略
```bash
py -3.11 -m stock_selector.main \
  --turnover 10 \
  --change 0,3 \
  --volume 1.3 \
  --sector 25 \
  --mainboard-only
```

### 示例2：自定义激进策略
```bash
py -3.11 -m stock_selector.main \
  --turnover 25 \
  --change 4,8 \
  --volume 3.0 \
  --sector 10 \
  --no-kdj \
  --no-rsi
```

### 示例3：在现有预设基础上微调
```bash
# 使用激进策略，但降低量能要求
py -3.11 -m stock_selector.main --preset aggressive --volume 2.0

# 使用保守策略，但调整涨幅区间
py -3.11 -m stock_selector.main --preset conservative --change 1,4
```

## 参数详解

### 数值参数

| 参数 | 说明 | 推荐范围 | 示例 |
|------|------|----------|------|
| `turnover` | 最低换手率(%) | 5-30 | `turnover: 15.0` |
| `change` | 涨跌幅区间(%) | [-5, 10] | `change: [1, 3]` |
| `volume` | 量能放大倍数 | 1.1-5.0 | `volume: 1.5` |
| `sector` | 每板块最多数量 | 5-50, 0不限 | `sector: 20` |

### 布尔参数

| 参数 | 说明 | 默认值 | 效果 |
|------|------|--------|------|
| `check_outer_inner` | 检查外盘>内盘 | true | 要求主动买入>主动卖出 |
| `check_kdj` | 检查KDJ未超买 | true | 要求KDJ_K < 80 |
| `check_rsi` | 检查RSI未超买 | true | 要求RSI6 < 70 |
| `filter_cyb` | 过滤创业板 | false | 过滤3开头股票 |
| `filter_kcb` | 过滤科创板 | false | 过滤688开头股票 |
| `mainboard_only` | 只选主板 | false | 同时过滤创业板和科创板 |

## 策略设计技巧

### 1. 根据市场环境调整

#### 牛市环境
```yaml
bull_market:
  turnover: 20.0
  change: [3, 7]
  volume: 2.5
  check_kdj: false  # 牛市允许超买
  check_rsi: false
```

#### 熊市环境
```yaml
bear_market:
  turnover: 8.0
  change: [0, 2]
  volume: 1.2
  check_kdj: true   # 熊市严格控制
  check_rsi: true
  mainboard_only: true
```

#### 震荡市
```yaml
range_market:
  turnover: 12.0
  change: [1, 3]
  volume: 1.5
  check_kdj: true
  check_rsi: true
```

### 2. 根据个人风格调整

#### 保守型投资者
- 低换手率（5-10%）
- 小涨幅（0-3%）
- 温和放量（1.2-1.5倍）
- 只选主板（`mainboard_only: true`）
- 严格技术指标（`check_kdj: true`, `check_rsi: true`）

#### 激进型投资者
- 高换手率（20-30%）
- 大涨幅（3-8%）
- 强放量（2.5-4倍）
- 不限制板块
- 允许超买（`check_kdj: false`, `check_rsi: false`）

#### 平衡型投资者
- 中等换手率（12-18%）
- 适中涨幅（1-5%）
- 正常放量（1.5-2.5倍）
- 根据市场情况调整技术指标

### 3. 根据操作周期调整

#### 超短线（1-2天）
```yaml
ultra_short:
  turnover: 25.0
  change: [2, 5]
  volume: 3.0
  sector: 10
```

#### 短线（3-5天）
```yaml
short_term:
  turnover: 15.0
  change: [1, 4]
  volume: 1.8
  sector: 20
```

#### 中短线（5-10天）
```yaml
medium_term:
  turnover: 10.0
  change: [0, 3]
  volume: 1.3
  sector: 30
```

## 常见问题

### Q1: 如何测试新策略是否有效？
**A**: 分两步：
1. 先用命令行参数测试：
   ```bash
   py -3.11 -m stock_selector.main --turnover 12 --change 1,5 --volume 1.8
   ```
2. 确认效果好后，再添加到 `presets.yaml`

### Q2: 策略参数如何调整才能选出更多股票？
**A**: 降低筛选条件：
- 降低换手率：`turnover: 8.0`
- 扩大涨幅区间：`change: [0, 5]`
- 降低量能：`volume: 1.2`
- 增加板块限制：`sector: 30` 或 `sector: 0`
- 关闭部分检查：`check_kdj: false`

### Q3: 如何选出更精准但更少的股票？
**A**: 提高筛选条件：
- 提高换手率：`turnover: 25.0`
- 缩小涨幅区间：`change: [2, 4]`
- 提高量能：`volume: 3.0`
- 减少板块限制：`sector: 5`
- 开启所有检查

### Q4: 策略名称有什么要求？
**A**: 
- 只能包含字母、数字、下划线
- 不能以数字开头
- 建议使用英文命名
- 例如：`my_strategy`, `strategy_2024`, `ultra_short_v2`

### Q5: 修改配置文件后需要重启程序吗？
**A**: 不需要，每次运行都会重新加载配置文件

### Q6: 可以定义多少个策略？
**A**: 没有限制，但建议不超过20个，太多不好管理

## 策略模板

### 通用模板
```yaml
  your_strategy_name:
    # 基础筛选
    turnover: 15.0           # 换手率 > X%
    change: [1, 3]           # 涨幅 X% ~ Y%
    volume: 1.5              # 量能 > X倍
    sector: 20               # 每板块最多X只（0不限）
    
    # 技术指标
    check_outer_inner: true  # 检查外盘>内盘
    check_kdj: true          # 检查KDJ未超买
    check_rsi: true          # 检查RSI未超买
    
    # 板块过滤
    filter_cyb: false        # 过滤创业板
    filter_kcb: false        # 过滤科创板
    mainboard_only: false    # 只选主板
```

### 复制此模板，修改参数，保存到 presets.yaml 即可！

**推荐流程**：
1. 先用命令行测试参数组合
2. 找到合适的参数后添加到 `presets.yaml`
3. 起个好记的名字
4. 使用 `--preset your_strategy_name` 快速调用

**快速开始**：
```bash
# 1. 测试参数
py -3.11 -m stock_selector.main --turnover 12 --change 1,5 --volume 1.8

# 2. 效果好，添加到 presets.yaml
# 3. 使用预设
py -3.11 -m stock_selector.main --preset my_strategy
```
