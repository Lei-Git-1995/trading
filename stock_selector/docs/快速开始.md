# 股票选股系统 - 快速使用指南

## 一、日常执行命令

### Windows 图形界面

源码运行：

```powershell
py -3.11 -m stock_selector.gui_app
```

构建独立程序：

```powershell
powershell -ExecutionPolicy Bypass -File E:\trading\stock_selector\build_gui.ps1
```

程序位于 `E:\trading\dist\StockSelector\StockSelector.exe`。分发时复制整个 `StockSelector` 文件夹，保留 `_internal/`、`data/` 和旁边的 `presets.yaml`、`presets_v2.yaml`；只复制 exe 无法运行。

策略下拉框显示中文含义；原英文策略 ID 仍用于 YAML 配置和命令行参数。自定义常规预设可增加 `display_name` 字段设置界面名称。

选股结果表会显示行业/板块、换手率、量比、成交量和成交额。东方财富数据源提供行业名称；腾讯/新浪数据源的行业字段不可用时显示其市场板块分类。

大盘右侧行业榜优先使用东方财富约 200 个细分行业，并按主力净流入排序，因此可以显示“元件”“印制电路板”等细分行业；东方财富不可用时才回退腾讯的较粗行业榜，面板会标注当前数据源。

GUI 支持自动刷新，默认间隔 60 秒。第一次运行会下载并缓存历史 K 线，后续刷新优先读取 `data/.cache/<数据源>/`，技术形态历史数据还会使用并发请求，因此刷新速度会明显快于首次运行。

### 命令行运行

### 1. 使用默认参数
```bash
cd E:\trading
py -3.11 -m stock_selector.main
```

### 2. 使用预设策略（推荐）

**查看所有预设**：
```bash
py -3.11 -m stock_selector.main --list-presets
```

**激进策略**（捕捉强势股）：
```bash
py -3.11 -m stock_selector.main --preset aggressive
```

**保守策略**（稳健标的，过滤创业板/科创板）：
```bash
py -3.11 -m stock_selector.main --preset conservative
```

**低吸策略**（允许小跌，寻找反弹机会）：
```bash
py -3.11 -m stock_selector.main --preset dip_buying
```

**突破策略**（大幅放量突破）：
```bash
py -3.11 -m stock_selector.main --preset breakout
```

### 3. 自定义参数

**完全自定义**：
```bash
py -3.11 -m stock_selector.main --turnover 12 --change 1,5 --volume 1.8
```

**在预设基础上微调**：
```bash
# 使用激进策略，但降低量能要求
py -3.11 -m stock_selector.main --preset aggressive --volume 2.0

# 使用保守策略，但调整涨幅区间
py -3.11 -m stock_selector.main --preset conservative --change 0,2
```

### 4. 其他实用选项

**交互式输入**（适合探索不同参数）：
```bash
py -3.11 -m stock_selector.main -i
```

**不使用缓存**（确保最新数据）：
```bash
py -3.11 -m stock_selector.main --no-cache
```

**调试模式**（显示详细日志）：
```bash
py -3.11 -m stock_selector.main --log-level DEBUG
```

**不记录日志文件**：
```bash
py -3.11 -m stock_selector.main --no-log-file
```

## 二、预设策略说明

| 预设名称 | 换手率 | 涨跌幅 | 量能 | 适用场景 |
|---------|--------|--------|------|---------|
| `default` | >15% | 1~3% | >1.5倍 | 日常选股，适中标准 |
| `aggressive` | >20% | 3~7% | >2.5倍 | 捕捉强势股，追涨 |
| `conservative` | >8% | 0~3% | >1.2倍 | 稳健标的，过滤创业板/科创板 |
| `dip_buying` | >12% | -2~2% | >1.8倍 | 低吸反弹，允许小跌 |
| `breakout` | >18% | 2~5% | >3.0倍 | 放量突破，不限制超买 |
| `mainboard_only` | >12% | 1~4% | >1.5倍 | 只选主板股 |

## 三、输出文件

- **常规选股报告**：`stock_selector/output/YYYY-MM-DD.md`
- **批量选股结果**：`stock_selector/output/YYYY-MM-DD/summary.md` 和各策略子目录中的 `report.md`
- **日志文件**：`stock_selector/logs/YYYY-MM-DD.log`

## 四、参数说明

### 筛选参数
- `--turnover`: 最低换手率（%），默认15
- `--change`: 涨跌幅区间（%），格式：最小值,最大值，如 `1,3` 或 `-2,2`
- `--volume`: 量能放大倍数，默认1.5
- `--sector`: 每个板块最多数量，默认20（0不限制）

### 过滤选项
- `--no-outer`: 不检查外盘内盘关系
- `--no-kdj`: 不检查KDJ超买（K<80）
- `--no-rsi`: 不检查RSI超买（RSI6<70）
- `--no-cyb`: 过滤创业板（3开头）
- `--no-kcb`: 过滤科创板（688开头）

### 数据源
- `--source`: 指定数据源（eastmoney/tencent/akshare），默认东方财富

### 日志选项
- `--log-level`: 日志级别（DEBUG/INFO/WARNING/ERROR），默认INFO
- `--log-file`: 日志文件路径
- `--no-log-file`: 不写入日志文件

## 七、常见问题

### Q: 如何添加自定义预设？
A: 编辑 `stock_selector/presets.yaml` 文件，参考现有预设格式添加新的配置。

### Q: 日志文件在哪里？
A: 命令行默认在 `stock_selector/logs/YYYY-MM-DD.log`；批量选股日志位于当天输出目录的 `run.log`。

### Q: 如何关闭进度条？
A: 卸载 tqdm：`pip uninstall tqdm`（系统会自动降级为简单进度提示）

### Q: 预设和命令行参数冲突怎么办？
A: 命令行参数优先级更高，会覆盖预设中的对应值。

## AI 大模型配置与 LLM 分析

主界面的「配置」页用于填写大模型参数（兼容 OpenAI Chat Completions 接口）：API 地址、API Key、模型、超时、温度、max_tokens，以及连续分析的盘中间隔。点击「保存配置」后写入本地文件 `config.local.json`（位于程序目录，打包后与 exe 同级），密钥不入数据库。

```json
{
  "llm": {
    "enabled": true,
    "base_url": "https://api.openai.com/v1",
    "api_key": "",
    "model": "gpt-4o-mini",
    "timeout_sec": 180,
    "temperature": 0.2,
    "max_tokens": 4096
  },
  "agent": { "enabled": false, "interval_sec": 300 }
}
```

配置好之后，「LLM 分析」页可对当日选股候选做一次或连续研判，结果写入 PostgreSQL（`agent_analyses` / `agent_picks`）供回看。分析输出为结构化 JSON（含买入/卖出/观望建议、目标价与止损价），仅用于策略验证，不代表真实市场成交。

## Agent 自动模拟交易

“配置”页可设置内置模拟盘的初始资金、单票仓位上限、硬止损和止盈比例。勾选“启用 Agent 自动模拟买卖”并保存后，Agent 的盘中连续分析周期会自动处理模拟委托；该开关默认关闭。

每轮先刷新持仓行情并检查硬止损/止盈，再处理大模型建议。自动买入仅限本轮选股候选、取得腾讯实时行情且满足置信度、可用现金、单票仓位和开仓时间限制的股票；每只股票每日最多自动买入一次。卖出受 A 股 T+1 约束，止损触发但当日不可卖时会记录为未成交，在后续周期继续检查。学习周期会结合模拟盘成交记录和盈亏进行复盘，不会下单。

模拟盘委托、现金、持仓、止盈止损价格和成交盈亏保存于 PostgreSQL。所有自动成交均按取到的行情价模拟，不能保证收益，也不会提交真实券商委托。

大盘行业板块表展示主力净流入（亿元）、涨幅、上涨家数、涨停数和上涨比。主力净流入及涨幅、上涨/下跌/平盘家数来自东方财富行业板块列表接口；程序按上涨家数 ÷ 板块成分家数计算上涨比。行业涨停数尝试读取同一接口的涨停字段；数据源或回退源没有提供该字段时显示“—”。致富研究员当前保存的 `market_overview.json` 含行业 `main_net_yi`、`pct_chg`、`up`、`down`、`flat`、`member` 和 `up_ratio`，但没有逐行业涨停数字段；它另有全市场涨停情绪统计。
