# 文档和模板

本目录包含股票分析相关的文档和模板文件。

## 目录内容

### 模板文件

- `stock_analysis_template.md` - 分析报告模板
  - 用于生成标准化的技术分析报告
  - 包含所有占位符和格式定义

### 使用文档

如果有其他操作手册，也会存放在此目录。

## 自定义模板

### 模板位置

默认模板路径在 `config.py` 中配置：

```python
PATHS = {
    'template': PROJECT_ROOT / 'docs' / 'stock_analysis_template.md',
}
```

### 模板变量

模板使用 `{{变量名}}` 格式的占位符：

**基本信息:**
- `{{股票代码}}` - 股票代码
- `{{股票名称}}` - 股票名称
- `{{所属行业}}` - 所属行业
- `{{交易所}}` - 交易所名称
- `{{报告日期}}` - 报告生成日期
- `{{最新日期}}` - 数据最新日期

**实时行情:**
- `{{最新价}}` - 最新价格
- `{{涨跌额}}` - 涨跌额
- `{{涨跌幅}}` - 涨跌幅
- `{{今开}}` - 今日开盘价
- `{{昨收}}` - 昨日收盘价
- `{{最高}}` - 最高价
- `{{最低}}` - 最低价
- `{{成交量}}` - 成交量
- `{{成交额}}` - 成交额
- `{{换手率}}` - 换手率
- `{{振幅}}` - 振幅
- `{{量比}}` - 量比
- `{{市盈率}}` - 市盈率
- `{{市净率}}` - 市净率
- `{{总市值}}` - 总市值
- `{{流通市值}}` - 流通市值

**技术指标:**
- `{{MA5}}`, `{{MA10}}`, `{{MA20}}`, `{{MA60}}` - 均线
- `{{MACD_DIF}}`, `{{MACD_DEA}}`, `{{MACD_BAR}}` - MACD指标
- `{{KDJ_K}}`, `{{KDJ_D}}`, `{{KDJ_J}}` - KDJ指标
- `{{RSI6}}`, `{{RSI12}}`, `{{RSI24}}` - RSI指标
- `{{BOLL_UPPER}}`, `{{BOLL_MID}}`, `{{BOLL_LOWER}}` - 布林带

**分析结果:**
- `{{趋势判断}}` - 趋势描述
- `{{均线排列}}` - 均线排列状态
- `{{MACD信号}}` - MACD信号（金叉/死叉）
- `{{MACD分析}}` - MACD分析文字
- `{{KDJ状态}}` - KDJ状态（超买/超卖/正常）
- `{{RSI状态}}` - RSI状态
- `{{BOLL位置}}` - 布林带位置

**支撑压力:**
- `{{强支撑}}`, `{{次支撑}}`, `{{弱支撑}}` - 支撑位
- `{{强压力}}`, `{{次压力}}`, `{{弱压力}}` - 压力位

**操作建议:**
- `{{短线方向}}`, `{{短线理由}}`, `{{短线买入价}}`, `{{短线止损}}`, `{{短线目标}}`
- `{{中线方向}}`, `{{中线理由}}`, `{{中线关注}}`, `{{中线止损}}`, `{{中线目标}}`

**其他:**
- `{{近10日数据}}` - 近10日数据表格
- `{{风险提示}}` - 风险提示内容
- `{{生成时间}}` - 报告生成时间

### 创建自定义模板

1. 复制默认模板：
```bash
cp stock_analysis/docs/stock_analysis_template.md stock_analysis/docs/my_template.md
```

2. 编辑模板内容

3. 使用自定义模板：
```bash
python -m stock_analysis 600519 --template stock_analysis/docs/my_template.md
```

或在代码中：
```python
analyzer = StockAnalyzer('600519')
analyzer.generate_report(template_path='stock_analysis/docs/my_template.md')
```
