# 选股指标与策略说明

本项目的选股模块位于 `core/selection.py`，启动入口为 `select_stocks.py`。它对每只股票的日线数据计算指标，再按策略条件筛选。策略输出是技术条件匹配结果，不代表收益承诺；实盘前应加入停牌、ST、上市天数、流动性、涨跌停和风险控制过滤，并进行历史回测。

## 一、已配置的指标

| 指标 | 当前参数 | 用途 |
|---|---:|---|
| MA | 5、10、20、60、120 | 短中长期趋势、均线排列 |
| EMA | 12、26、50 | 更快识别趋势变化 |
| MACD | 12、26、9 | 金叉、死叉、动能方向 |
| KDJ | 9、3、3 | 短线超买超卖 |
| RSI | 6、12、24 | 短中长期强弱和回升 |
| BOLL | 20、2倍标准差 | 突破、回归和波动率 |
| 成交量均线 | 5、20 | 量比和放量判断 |
| ATR | 14 | 波动率、止损距离和仓位计算 |
| OBV | 20日均线 | 量价背离和资金累积辅助判断 |
| ADX | 14 | 趋势强度过滤 |

120日均线、ATR、OBV、ADX和成交量均线是新增的固定指标。后续如果接入基本面数据，建议再增加市值、流通市值、PE、PB、ROE、营收/净利润增速、负债率和自由现金流等过滤项；这些数据当前数据源接口尚未统一提供，因此没有直接写入技术选股条件。

## 二、固定指标策略

### 1. 均线多头趋势（`ma_trend`）

条件：MA5 > MA10 > MA20，最新收盘价在 MA20 上方，且 MA20 相比5个交易日前上行。

### 2. MACD金叉（`macd_cross`）

条件：最近3个交易日内 DIF 向上穿越 DEA，MACD柱为正，收盘价在 MA20 上方。

### 3. RSI回升（`rsi_rebound`）

条件：RSI6 位于35至65之间并较前一日回升，RSI12不低于45。

### 4. 布林上轨突破（`boll_breakout`）

条件：收盘价突破BOLL上轨，量比不低于1.2。需要额外检查是否已经连续大涨或接近涨停。

### 5. 放量突破（`volume_breakout`）

条件：收盘突破前20个交易日最高价，当日涨幅为正，成交量至少是20日平均成交量的1.5倍。

## 三、周期性形态策略

### 6. 温和连续上涨吸筹（`accumulation_3of10`）

默认观察最近10个交易日：其中至少出现连续3天上涨，并且这3天每天涨幅在1%至3%之间，最新收盘价位于MA20上方。

这个规则可以作为“主力吸筹”的技术代理信号，但连续小阳线也可能只是普通反弹或消息驱动，不能仅凭该形态判断主力行为。建议同时观察成交量、换手率、回撤幅度，并排除连续涨停和流动性不足的股票。

### 7. 回撤后反弹（`pullback_rebound`）

条件：最近10个交易日前段出现至少5%的回撤，最新价格重新站上MA5，当日上涨且量比不低于1.0。

## 四、多因子策略

### 8. 多因子综合（`multi_factor`）

对均线趋势、MACD金叉、放量突破、RSI回升、布林突破五项条件打分，至少满足三项才入选。它适合先得到候选池，再人工复核行业、基本面、消息面和风险收益比。

## 五、执行方式

```powershell
cd E:\trading
python -m stock_analysis.select_stocks --list-strategies
python -m stock_analysis.select_stocks --input E:\data\daily --strategy all
python -m stock_analysis.select_stocks --codes 600519,600036,000001 --strategy accumulation_3of10
```

不传 `--strategy` 或 `--input` 时，程序会启动交互模式，先显示所有策略，再让你选择策略和数据来源。结果默认保存到 `reports/selection_YYYYMMDD_HHMMSS.md`。
