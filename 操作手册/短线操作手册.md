# 短线操作手册（T+1 隔日超短体系）

> 版本 v1.0 ｜ 市场：A股 ｜ 周期：持股 1 天，极强势延长 2–3 天
> 本文是一套技术分析与纪律执行框架，用来规范你自己的决策流程，**不构成投资建议**。所有参数需用你自己的成交记录反复校准。盈亏自负。

---

## 0. 体系定位：你在做的是什么生意

你做的不是"预测"，是**接力**。

隔日超短的利润来源只有一个：**今天进场的资金，明天早盘还愿意用更高的价格接手。**
所以一切选股标准，最终只回答一句话——

> 「明天 9:25，会不会有比我更着急的人，出更高的价买走我的票？」

由这一句话推出三条铁律：

1. **只买"已经有人在买"的票**——承接 > 形态 > 故事。没有量的漂亮形态一律不碰。
2. **只在情绪能延续的窗口买**——退潮期的空仓，比任何技术都值钱。
3. **卖出不需要理由，持有才需要理由**——默认动作是"走"，够强才"留"。

你的规则「次日 10:30 前必走，除非非常强势」是正确的。本手册第 5、6 章就是把"非常强势"这四个字，拆成可执行、不带情绪的判定条件。

## 1. 资金与仓位规则（先定死，盘中不再讨论）

**资金分层**

| 层级 | 占总资金 | 是否受本手册管辖 |
|---|---|---|
| 底仓／中线仓 | 60–80% | 否，不许挪用 |
| **短线仓** | **20–40%** | **是** |

**短线仓内部规则**

- 单票上限 = 短线仓的 50%（即总资金的 10–20%）。
- 同时最多持 2 只；极强势行情只持 1 只。集中比分散有效，分散往往只是把错误摊成慢性亏损。
- 同一板块不许买两只——那不是分散，是加杠杆。
- 打板／追高单票只用短线仓 30%，低吸可用 50%。

**硬性止损线**

- 单票最大亏损 5%（打板票 3%）。
- 单日最大亏损 = **总资金 2%**。触及即当日停手，次日只看盘不下单。
- 连续三日亏损 → 强制空仓一天，只做复盘。

## 2. 第一道闸门：今天到底能不能做（大盘情绪周期）

**这一步没通过，后面全部作废。任何选股技巧都救不了退潮期。**

每天 14:00–14:30 用五个数据判断市场处在哪个阶段（用东财／通达信／同顺的涨停板块统计页即可）：

| 指标 | 含义 |
|---|---|
| 涨停家数 | 资金进攻强度 |
| 跌停家数 | 恐慌程度 |
| **昨日涨停今日表现（连板率／溢价率）** | **最关键：接力资金还在不在** |
| 炸板率 | 封板质量，> 40% 说明高位承接开始崩 |
| 上涨家数／下跌家数 | 赚钱效应广度 |

### 情绪周期四阶段与对应动作

| 阶段 | 识别特征 | 做什么 |
|---|---|---|
| **① 冰点／启动** | 涨停 < 30 家，跌停多，但出现 1–2 个放量首板且次日溢价明显 | 试仓 1/3，只做首板低吸 |
| **② 主升／发酵** | 涨停 60–100+ 家，连板梯队完整（3板/4板都有），昨日涨停今日红盘率 > 60% | **主战场，满短线仓，敢于打板** |
| **③ 高潮／分歧** | 涨停 100+ 但炸板率 > 40%，最高标出现天量换手或首次跌停，题材开始"补涨股比龙头涨得好" | 减半仓，只做低吸不追高，缩短持股周期 |
| **④ 退潮** | 昨日涨停今日绿盘率 > 50%，连板梯队断层（只剩1个高位板），跌停家数抬头 | **空仓。这是本手册最重要的一条。** |

### 一票否决（当天不做任何短线）

- 昨日涨停股今日**平均收益为负**，且绿盘超半数 → 接力链条已断。
- 指数放量跌破 5 日线并且个股跌幅中位数 < −2%。
- 最高标（市场最高连板）今日**炸板或跌停** → 当日不接任何高位股。
- 隔夜出现方向不明的重大消息（政策、外盘暴跌、大额解禁潮）。

> 一年里真正适合隔日超短的日子大约只有 40%。**空仓不是没操作，空仓是操作。**

# 3. 【核心】选股：今天该选什么样的股

## 3.0 选股总纲：五维共振

一只合格的隔日短线标的，必须同时满足下面五个维度。**缺一个都不买**，宁可空仓。

```
      ┌──────────────┐
      │  ① 题材／逻辑 │  有没有人愿意讲故事（明天的接盘理由）
      └──────┬───────┘
      ┌──────┴───────┐
      │  ② 板块地位   │  它是不是这个故事里最强的那个
      └──────┬───────┘
      ┌──────┴───────┐
      │  ③ 日K位置    │  上方有没有套牢盘挡路
      └──────┬───────┘
      ┌──────┴───────┐
      │  ④ 量能／筹码  │  钱是真进来了，还是只是价格动了
      └──────┬───────┘
      ┌──────┴───────┐
      │  ⑤ 分时质量    │  今天买的人是坚决的，还是犹豫的
      └──────────────┘
```

记忆口诀：**「有故事、是龙头、没套牢、真放量、分时硬」**

---

## 3.1 硬性过滤（先把 90% 的票扔掉）

不满足以下任一条，**直接删除，不要看图，不要"觉得它有机会"**：

**A. 流动性与规格**

| 条件 | 阈值 | 原因 |
|---|---|---|
| 流通市值 | 30亿 – 200亿（最佳 40–120亿） | < 30亿易被操纵、次日容易一字闷杀；> 200亿拉不动，隔日空间不够 |
| 当日成交额 | **≥ 8亿**（题材主线 ≥ 15亿） | 你要能在集合竞价一笔走掉，不能砸自己 |
| 换手率 | 5% – 25%（首板 8–15% 最佳） | < 5% 无分歧无接力；> 30% 常是一日游 |
| 股价 | 5 – 60元 | 太低多为垃圾股，太高散户接力意愿差 |

**B. 一票否决清单（红线）**

- ❌ ST／\*ST／退市风险警示股
- ❌ 上市 < 60 个交易日的新股次新（波动无规律，缺乏筹码历史）
- ❌ 北交所、流动性差的科创板小票（除非你熟悉其盘口）
- ❌ 明日／本周有**解禁、财报预披露、重要股东减持公告、可转债转股**的
- ❌ 近 5 日有**减持公告、立案调查、问询函、业绩预亏、商誉暴雷**的
- ❌ **前期高位天量套牢盘就在头顶 5% 以内**（详见 3.4）
- ❌ 已连续 4 板以上的高位股（除非情绪处于②阶段且你是熟练打板选手）
- ❌ 今日为**放量长上影／跌破均价线收阴**的票，无论题材多好

> 严格执行 A+B 之后，全市场每天通常只剩 5–15 只候选。这才是正常状态。**清单太长说明你的标准太松。**

## 3.2 维度①：题材与逻辑——明天的接盘理由

短线不看基本面，但**必须看"叙事强度"**。次日买你股票的人，需要一个能在 3 秒内说服自己的理由。

### 题材分级（只做 S 级和 A 级）

| 级别 | 特征 | 例子类型 | 操作 |
|---|---|---|---|
| **S 级** | 政策级／产业级新变量，行业空间大，**当天板块内涨停 ≥ 5 家**，全市场资金聚焦 | 国家层面产业政策、突发技术突破、全球性事件驱动 | 主攻，可打板 |
| **A 级** | 有明确催化，板块内涨停 3–5 家，有龙头有梯队 | 行业订单／涨价、龙头公司业绩超预期带动全板块 | 可做，选龙二龙三低吸 |
| **B 级** | 只有 1–2 家涨停，无扩散 | 单一公司事件、蹭概念 | **不做**（无接力资金） |
| **C 级** | 纯技术形态，无逻辑 | 超跌反弹、单纯放量 | **不做隔日** |

### 题材鲜度（决定持股天数）

```
第 1 天  消息出现，首批涨停 ────► 最佳买点（次日溢价最高）
第 2 天  板块扩散，涨停家数增加 ─► 可买（买龙二／补涨龙头）
第 3 天  涨停家数见顶，开始分化 ─► 只减不加
第 4 天+ 补涨股比龙头强 ────────► 板块进入尾声，离场，不再介入
```

**核心判断：数"板块内今日涨停家数"的变化方向。**
- 昨天 3 家 → 今天 7 家 = **扩散中，可做**
- 昨天 8 家 → 今天 4 家 = **退潮中，不做**

这一个数字比任何指标都有用。

### 题材的三个加分项

1. **有龙头封死一字板或早盘快速板** → 说明有主力资金定调。
2. **有大级别想象空间**（"这个事能持续讲一个月"）。
3. **消息在收盘后／盘中新出现**，尚未被市场充分定价 → 次日有集合竞价溢价。

### 题材的三个减分项

1. 题材已经炒过 2 轮以上（"老题材翻炒"），次日容易高开低走。
2. 龙头是"没人认的"（无成交量、无标志性个股）。
3. 板块涨停股都是 5% 涨幅限制的 ST 或低价垃圾股 → 资金层次低。

## 3.3 维度②：板块地位——只买"最强的那一个"

**同一个题材里，永远只买前三名。第 5 名之后不值得持有隔夜。**

判定顺序（按优先级）：

1. **谁先涨停？**（时间最早 = 主力最坚决）
2. **谁封单最大？**（封单金额 / 流通市值 越高越硬）
3. **谁成交额最大？**（资金真正认可的那只）
4. **谁的连板高度最高？**

### 龙一 / 龙二 / 补涨的取舍

| 位置 | 优点 | 风险 | 隔日短线建议 |
|---|---|---|---|
| **龙一（最高标）** | 溢价最高，退潮时最抗跌 | 加速期一旦断板跌幅大 | ②阶段最优；③阶段禁买 |
| **龙二（跟风最强）** | 有龙一护体，空间打开 | 龙一炸板则同步崩 | **性价比最高，主选** |
| 龙三／补涨 | 位置低，安全边际 | 溢价薄，一日游概率高 | ③阶段可做，快进快出 |
| 尾部跟风 | —— | 次日大概率绿盘 | **永不做** |

### 一个实用的反向指标

如果你发现**补涨股涨得比龙头还猛**、龙头开始滞涨——这是板块见顶信号，不是"轮动机会"。当天减仓，明日不接。

## 3.4 维度③：日K线位置——上方有没有人挡路

**这是最容易被忽视、也最容易致命的一条。** 隔日短线怕的不是"涨太多"，是"头上有套牢盘"。

### ✅ 优质位置（可买）

**形态 1：平台突破（最稳，首选）**
```
   涨停放量突破 ←── 今天
         ▲
   ┌────┐│
───┘    └┴──   横盘 10–30 天，缩量
```
- 横盘期间成交量逐步萎缩（洗盘充分），突破日量能放大 2 倍以上。
- 平台之上无历史套牢区。
- 次日溢价来源：技术派、趋势资金、量化都会在突破次日介入。

**形态 2：底部第一次放量涨停（空间最大）**
- 股价在半年低位区，长期缩量。
- 今日首次涨停且量能 > 5 日均量 3 倍。
- 上方筹码稀薄（下跌过程已充分换手）。
- 风险：可能只是一日反弹，需要分时质量确认。

**形态 3：强势股回踩 5 / 10 日线的第一次企稳（低吸首选）**
```
     ／＼
    ／   ＼＿  ← 缩量回调至5日线
   ／       ／  ← 今天放量重新拉起（今天买）
  ／
```
- 主升趋势未破（5 日线上行，均线多头）。
- 回调**缩量**（缩至前高量的 50% 以下），今天**放量**重新收阳／涨停。
- 这是隔日短线胜率最高的形态，因为止损位极清晰（跌破 10 日线）。

**形态 4：连板加速中的一板／二板（收益最高，风险也最高）**
- 只在情绪②阶段做，且必须是龙一龙二。
- 二板是隔日溢价的黄金位置（"上不封顶、下有支撑"）。

### ❌ 劣质位置（禁买）

| 形态 | 为什么禁 |
|---|---|
| **头上有前期天量密集区（距现价 < 8%）** | 明天一开盘就是解套盘砸你 |
| 连续 5 日累计涨幅 > 35% 且今日冲高回落 | 加速末端，随时崩 |
| 长期下降趋势中的反抽（均线空头排列压制） | 每根均线都是卖压 |
| 天量长上影线 / 高位十字星 | 分歧已经出现且卖方赢了 |
| 今日**跌破昨日涨停板的实体一半** | 昨日买入者全部亏损，明天砸盘 |
| 已 4 板以上、且今日封板时间晚于昨日 | 资金接力意愿在减弱 |

### 均线要求（简单但有效）

- **必须：** 收盘价 > MA5 > MA10，且 MA5 上行。
- **加分：** MA20 上行、MA60 走平或上行（大趋势不背离）。
- **禁止：** 股价在 MA60 下方且 MA60 下行（这叫下跌中继）。

## 3.5 维度④：量能与筹码——钱是不是真的进来了

### 3.5.1 量能三条铁律

**铁律一：突破必须放量，回调必须缩量。**

| 场景 | 合格标准（对比 5 日均量） |
|---|---|
| 突破／涨停日 | **≥ 2 倍**（首板底部启动最好 ≥ 3 倍） |
| 平台横盘期 | ≤ 0.6 倍 |
| 回调低吸买点日 | 回调时 ≤ 0.5 倍，买入当日重新 ≥ 1.5 倍 |
| 连板股 | 二板量能可比首板放大，**三板后缩量封板才是最强**（一字板无量=锁筹极好） |

**铁律二：警惕"天量"。**
换手率 > 30%，或成交量创**历史／年内最大**且股价冲高回落 → 这通常是出货，不是进货。次日大概率低开。

**铁律三：量价背离一律回避。**
- 股价新高，成交量**萎缩** → 无人接力，随时回落。
- 股价横住，成交量**暴增** → 有人在派发。

### 3.5.2 量能形态图解

```
健康（可买）              危险（不买）
                          
    █                          █
  █ █ █                      █ █
█ █ █ █ █                  █ █ █ █ █
─────────                  ─────────
逐步温和放大，              脉冲式天量后
突破日最大                  迅速衰减
```

### 3.5.3 筹码分布（CYQ）怎么用

筹码图是隔日短线**判断"明天有没有人砸你"的最直接工具**。看三样：

**① 获利盘比例**
- 获利盘 **> 90%** 且集中在下方 → 无人套牢，抛压极小 → **强烈加分**。
- 获利盘 60–90% → 正常，可做。
- 获利盘 < 50%，上方大量套牢 → 每涨一点都有解套抛压 → **减分／不做**。

**② 筹码集中度（形态）**

```
【单峰密集 · 低位】✅ 最佳
        ████████        ← 筹码在当前价附近高度集中
        ████████           上方几乎无套牢盘
   ─────────────── 现价     突破后阻力极小

【双峰 · 上方有大峰】❌ 危险
   ██████████           ← 前期高位套牢峰（明天的卖压）
        ░░
     ████               ← 你现在买的位置
   ─────────── 现价        涨到上峰必被砸

【上密下疏 · 派发中】❌ 禁买
   ████████             ← 高位新增大量筹码 = 主力已换手给散户
      ░░░
     ░░
```

**③ 筹码迁移速度（最有价值的信号）**
连续 2–3 天观察：如果**低位筹码峰快速消失、在当前价格上方形成新的密集峰**，说明主力正在把货交给追高盘 → 立即回避。
反之，若**筹码整体向上平移且保持单峰密集**，说明是良性换手 → 可持有。

**④ 平均成本线**
- 现价距市场平均成本 **+5% 以内**：安全，大家都小赚，不急于卖。
- 现价距平均成本 **> +20%**：全场浮盈过高，任何风吹草动都会引发获利了结。

### 3.5.4 涨停板的封单质量（打板专用）

| 指标 | 强 | 弱 |
|---|---|---|
| 封单额 / 流通市值 | > 3% | < 1% |
| 封板时间 | 10:00 前 | 14:30 后 |
| 封板过程 | 一次性打上不开板 | 反复开板（换手过多 = 抛压重） |
| 尾盘封单变化 | 持续增加 | 尾盘急速抽单（**必走**） |
| 是否触发触及涨停后回落 | 无 | 有炸板即降级 |

## 3.6 维度⑤：分时图质量——今天买的人坚决吗

**同样收涨 7%，分时形态不同，次日溢价天差地别。** 这是隔日短线的最后一道确认。

### ✅ 强势分时（买）

**① 早盘快速拉升 + 全天在均价线上方运行**
```
涨停 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
        ╱▔▔▔▔▔▔▔▔▔▔▔▔   ← 拉起后横盘不回落
      ╱  ····均价线····
    ╱
 ─┴─────────────────────
 9:30  10:30  13:00  15:00
```
判定：**股价全天不破均价线**（跌破立即拉回也算），尾盘不跳水 → 说明持筹者不卖。

**② 阶梯式上涨（多波段，一波比一波高）**
```
    ┌──
  ┌─┘      每次回调不破前一平台
┌─┘        = 资金分批建仓，不是一次性对倒
```
这是**最健康**的分时形态，次日高开概率最大。

**③ 尾盘 14:30 后放量拉升／直接封板**
说明有资金**愿意用收盘价拿隔夜票**——这就是明天替你抬轿的人。**这是隔日短线最强的单一信号。**

**④ 一字板 / 早盘秒板后封死**
锁筹最好，次日通常直接高开。

### ❌ 弱势分时（不买 / 有货就卖）

| 形态 | 图示 | 含义 |
|---|---|---|
| **冲高回落，尾盘破均价** | `╱▔╲___` | 上方抛压重，次日必低开 |
| **一波拉高后全天阴跌** | `╱╲___` | 拉高出货 |
| **反复上下穿均价线（毛刺形）** | `∿∿∿∿` | 多空分歧大，无主导资金 |
| **尾盘 14:45 后跳水** | `▔▔▔╲` | 有资金不愿留隔夜 → **你也别留** |
| **涨停炸板后不再封回** | `▔▔╲__` | 封板资金已撤 |
| **均价线向下倾斜** | `···╲` | 越买越贵的人在减少 |

### 分时的量价配合

- **拉升时放量，回调时缩量** → 真实买盘。
- **拉升时无量（对倒／脉冲），回调时放量** → 假拉升，坚决不碰。
- 分时上出现**连续大单扫货**（红柱密集且成交明细单笔量大） → 加分。

## 3.7 选股实战流程：每天 30 分钟做完

### 第一遍：14:00–14:20 建立候选池

依次跑三个来源：

1. **涨停板列表** → 记录每个板块涨停家数，找出今日最强板块（涨停 ≥ 3 家）。
2. **涨幅榜 5%–9%** → 找即将涨停或强势未封板的（这类隔日风险比打板小）。
3. **量比排行 + 换手率排行** → 找异动放量票，交叉验证是否属于最强板块。

**只保留：属于今日最强 1–2 个板块，且排名该板块前三的股票。**

### 第二遍：14:20–14:40 逐票过滤

对候选池每只票，按顺序打勾，**任一不合格立即删除**：

```
[ ] 硬性过滤全过（市值/成交额/换手/无雷）        → 3.1
[ ] 题材 S 级或 A 级，且板块涨停家数在增加        → 3.2
[ ] 是板块前三名                                → 3.3
[ ] 日K位置：平台突破 / 底部首板 / 回踩企稳       → 3.4
[ ] 收盘价 > MA5 > MA10，MA5 上行                → 3.4
[ ] 头上 8% 内无天量套牢区                       → 3.4
[ ] 量能 ≥ 2 倍 5 日均量，非天量                 → 3.5
[ ] 筹码单峰密集 / 获利盘 > 80% / 上方无大峰      → 3.5
[ ] 分时全天在均价线上方，尾盘不跳水              → 3.6
```

### 第三遍：14:40–14:57 定档买入

按得分排序，**只买第 1 名（最多前 2 名）**。

### 第四遍：收盘后 20 分钟

- 记录买入理由（写下来，一句话），次日复盘对照。
- 检查所买个股当晚**有无公告**（这是唯一能在盘后规避的风险）。
- 预设次日三个价格：**目标价、止损价、观察价**（见第 5 章）。

---

## 3.8 打分卡（把主观变客观）

每只候选票打分，**≥ 75 分才买，≥ 85 分才可以用满仓位**。

| 维度 | 权重 | 满分条件 |
|---|---|---|
| 板块强度（涨停家数 + 是否扩散） | 25 | 板块涨停 ≥ 5 家且家数比昨日增加 |
| 个股板块地位 | 20 | 龙一或龙二 |
| 日K位置 | 20 | 平台突破 / 回踩企稳，头上无套牢 |
| 量能健康度 | 15 | 2–4 倍温和放量，非天量 |
| 筹码结构 | 10 | 单峰密集，获利盘 > 85% |
| 分时质量 | 10 | 全天均价线上方 + 尾盘拉升 |

> 把这张表做成 Excel，每天填。**三个月后你会发现自己 70% 的亏损都来自 75 分以下的票。**

# 4. 买入执行

## 4.1 三种买法，按情绪阶段选

| 买法 | 时间窗口 | 适用情绪阶段 | 仓位 | 优点／代价 |
|---|---|---|---|---|
| **A. 尾盘定档**（主力打法） | 14:40–14:57 | ①②③ 全适用 | 短线仓 50% | 信息最完整（分时已走完、量能已定型），但吃不到当天涨幅 |
| **B. 打板** | 涨停瞬间 | **仅 ②** | 短线仓 30% | 溢价最高，炸板即亏 3–5% |
| **C. 回踩低吸** | 10:00–11:00 或 13:00–14:00 | ①③ | 短线仓 50% | 成本低、止损清晰，但需盘中盯盘 |

**你的资金体量和"次日 10:30 必走"的规则，最匹配 A（尾盘定档）。** 理由：尾盘买入时今天的分时、量能、筹码全部已知，等于用最完整的信息做决策，而隔日溢价主要产生在次日集合竞价到 10:00，你并不需要吃当天的肉。

## 4.2 尾盘定档的操作细节

1. **14:40 前完成选股**，只留 1–2 只，写好买入理由。
2. **14:45 观察最后确认**：分时是否仍在均价线上方？量能是否还在温和放大？如果此刻开始跳水 → **放弃，不买**。
3. **14:50–14:57 分两笔下单**（各 50%），避免一笔冲高自己的成本。
4. **不追高**：如果尾盘 3 分钟突然拉升超过 2%，放弃——那是别人在抢，你的成本会变差。
5. **绝不在 14:57 之后挂集合竞价买单**（尾盘集合竞价看不到对手盘，容易被闷）。

## 4.3 打板的补充规则（只在②阶段用）

- 只打**当日板块龙一或龙二的首板／二板**，不打三板以上。
- 封单额 / 流通市值 > 2% 才打；封单在你挂单后 1 分钟内明显减少 → 撤单。
- **炸板即走**，不等回封。打板体系里唯一的死法就是"等它封回来"。
- 14:00 之后才涨停的板不打（封板太晚，锁筹不足）。

## 4.4 下单前的最后一问

> 「如果明天开盘 −5%，我会不会后悔买这只票？」

如果答案是"会"，说明你买的是情绪不是逻辑。**不买。**

# 5. 【核心】次日决策树：走 / 看 / 留

## 5.0 默认动作

**默认是走。** 10:30 是硬性闹钟，不是参考。
只有满足第 5.4 节列出的**"强势留仓条件"**，才允许延长持有——而且必须是**在 10:00 前就已经确认**，不许"再看看"。

---

## 5.1 第一关：9:15–9:25 集合竞价（决定 70% 的结果）

集合竞价是隔日短线最重要的信息窗口。**开盘价基本决定了你今天是赚钱还是止损。**

### 竞价三看

**① 看开盘幅度**

| 开盘幅度 | 含义 | 动作预案 |
|---|---|---|
| **+7% 以上／一字板** | 资金极度认可 | 留意能否封板，**可能留仓** |
| **+3% ~ +7%** | 健康高开 | 观察 9:30–10:00 走势后决定 |
| **0 ~ +3%** | 分歧，溢价被抢走 | 冲高即走，10:00 前离场 |
| **−3% ~ 0** | 弱，接力资金没来 | **开盘反抽即走，不等 10:30** |
| **−3% 以下** | 逻辑已破 | **9:30 开盘直接走，无条件** |

**② 看竞价量能（最关键，很多人只看价不看量）**

竞价成交量 vs 昨日全天成交量的比值：

| 竞价量 / 昨日总量 | 含义 |
|---|---|
| **> 3%** | 巨量竞价。若配合高开 = 大资金抢筹（好）；若配合低开 = 大资金出逃（**立即走**） |
| 1% – 3% | 正常，健康 |
| **< 0.5%** | 无人关注，缩量高开 = 虚高，一开盘就会回落 → **走** |

**③ 看竞价过程（9:20 之后不能撤单，所以 9:20–9:25 的变化是真实的）**

```
✅ 好：9:20 后价格逐级抬升，买盘持续增加
   ┄┄╱▔  → 说明真实资金在扫

❌ 坏：9:20 后价格逐级下压，或大额买单突然消失
   ▔▔╲┄  → 撤单诱多，开盘必砸
```

> **一条实战铁律：** 高开但竞价量极小 = 主力用小单拉高开盘价，为了在 9:30 之后倒货给你。这种票开盘 1 分钟内必须走。

---

## 5.2 第二关：9:30–10:00 开盘 30 分钟（执行窗口）

这 30 分钟内完成绝大部分卖出。核心只盯**一条线：分时均价线**。

```
      ╱▔▔▔▔▔▔  ← 站上均价线运行 = 强，可以继续看
    ╱ ·····均价线·····
  ╱
 ────────────────
       ╲
        ╲__▁▁▁  ← 跌破均价线且拉不回 = 立刻走
```

### 卖出判定（满足任一即卖）

| 触发条件 | 动作 |
|---|---|
| 开盘价跌破**昨日收盘价** | 反抽不创新高即走 |
| 跌破**分时均价线**且 5 分钟内未收回 | **立刻全部卖出** |
| 冲高后**回落幅度 > 开盘涨幅的一半** | 立刻卖 |
| 高开后**放量长阴柱**（单根 1 分钟量 > 竞价量） | 立刻卖 |
| 所属板块龙头**炸板／跳水** | 立刻卖（板块联动优先于个股形态） |
| 大盘 9:45 后加速下跌超 1% | 减半仓或全出 |
| 触及止损价（−5%，打板票 −3%） | **无条件卖，不许改止损价** |

### 卖出方法

- 强势票：分批挂高价，让它自己涨上来打掉。
- 弱势票：**直接对手价市价单打掉。** 犹豫 1 分钟的成本通常大于滑点。
- **绝不"再等一个反弹"**。隔日短线里，反弹通常只在你卖完之后出现。

---

## 5.3 三态判定表：走 / 看 / 留

这是本手册最需要背下来的一张表。

### 🔴 立刻走人（无条件，不讨论）

1. **竞价低开 −3% 以下**，或竞价放巨量而低开。
2. **开盘 10 分钟内跌破分时均价线**且未收回。
3. **跌破昨日涨停／大阳线实体的一半**（昨天买的人集体亏损，抛压会自我强化）。
4. **所属板块龙头炸板、跌停或核心逻辑被证伪**（辟谣、公告否认）。
5. **个股出利空**：减持、问询、立案、业绩下修、大额解禁。
6. **大盘系统性下跌**（指数跳空低开 > 1.5% 且不回补）。
7. **触及硬止损 −5%**（打板 −3%）。
8. **情绪已进入退潮期④**（昨日涨停股今日大面积绿盘）——哪怕你的票还是红的，也走。
9. 高开但**竞价量极度萎缩**（< 0.5%）。
10. 冲高时**出现天量长上影**（换手 > 25% 且回落）。

> 第 8 条最反人性，也最省钱。**在退潮期把红盘的票卖掉，是职业选手和散户的分界线。**

---

### 🟡 观察（10:30 前必须给出结论，不许拖到下午）

出现以下情况，允许你观察到 10:30，但**10:30 一到，只要没升级为"留"，就走**：

| 情况 | 观察要点 |
|---|---|
| 平开或小幅高开（0~+3%），股价在均价线上方震荡 | 看 10:00 后能否放量上攻；不能则走 |
| 高开后回落，但**在均价线上方获得支撑**并二次上攻 | 二次上攻需**放量**且创出当日新高，否则走 |
| 涨停后开板，但**封单还在快速回补** | 15 分钟内回封则留；不回封则走 |
| 板块整体走弱，但你的票是**最抗跌的那一只** | 只在情绪②阶段值得等；③④阶段直接走 |
| 大盘冲高回落，但个股逆势走强 | 逆势强度能否维持到 10:30 |

**观察期的两条纪律：**
- 观察不等于挂着不管——**止损价必须已经挂在系统里**。
- 观察期内不许补仓。补仓是趋势交易的动作，不是隔日短线的动作。

---

### 🟢 继续持有 1–2 天（"非常强势"的严格定义）

**必须同时满足以下 A、B、C 三组，缺一不可。**

**A 组 · 大环境（必须全满足）**
- [ ] 市场情绪处在 **②主升阶段**（涨停 > 60 家，昨日涨停今日红盘率 > 60%）。
- [ ] 所属板块**今日涨停家数 ≥ 昨日**（题材仍在扩散）。
- [ ] 大盘未破 5 日线。

**B 组 · 个股强度（至少满足 3 条，含★项必满足）**
- [ ] ★ **9:25 竞价高开 ≥ 5%**，且竞价量占昨日总量 1–3%（有量的高开）。
- [ ] ★ **10:00 前涨停或涨幅 > 7% 且未跌破均价线**。
- [ ] 它是板块**龙一或龙二**，且今日仍是板块内最强。
- [ ] 封板后**封单额 / 流通市值 > 2%** 且持续增加。
- [ ] 分时呈**阶梯上行**，每次回调不破均价线。
- [ ] 换手率适中（未出现 > 30% 的天量派发）。

**C 组 · 结构未破（必须全满足）**
- [ ] 头上 10% 内**无历史天量套牢区**。
- [ ] 筹码仍为**单峰密集**或良性向上平移，未出现"上密下疏"。
- [ ] 未出现放量长上影或高位十字星。

**留仓后的处置：**
- 只留**原仓位的 1/2**，另一半在 10:00 前先落袋（这叫"卖飞保护"，保证这一单已经赢了）。
- 次日止盈止损收紧：**跌破当日均价线即全出**，不再给第二次机会。
- **最多再持 2 个交易日。** 第三天无条件清空，不看形态。理由：三日后的溢价已属于趋势交易范畴，与本体系的止损逻辑不兼容。

---

## 5.4 特例：一字板 / 涨停不开板怎么处理

- **一字板开盘**：不卖，挂单观察。若全天不开板 → 可持有到次日（视作 B 组满足）。
- **开板后急速回封**（15 分钟内，且封单大于开板前）→ 继续持有。
- **开板后炸板不回封** → 立刻走，无论盈亏。
- **炸板后跌破均价线** → 已经晚了，市价单出。

# 6. 指标配合：怎么用，以及怎么不被骗

短线周期太短，**指标只做辅助确认，永远不做买入依据**。优先级永远是：

> **量能 > 分时 > 日K位置 > 筹码 > 指标**

| 指标 | 短线怎么用 | 陷阱 |
|---|---|---|
| **量比** | 开盘量比 > 2 说明资金关注；> 5 且高开是强势信号 | 量比大但价格下跌 = 出货 |
| **换手率** | 首板 8–15% 最佳；> 30% 警惕派发 | 小盘股换手天然偏高，要和自身历史比 |
| **MACD** | 只用日线金叉 + 零轴上方作为"趋势未破"的确认 | 短周期滞后严重，**不能用来做买卖点** |
| **KDJ** | 日线 J 值 > 100 提示过热，可作为减仓提示 | 强势股可以长期高位钝化，单独用会卖飞 |
| **RSI** | > 80 提示过热 | 同上，钝化常见 |
| **BOLL** | 股价沿上轨运行 = 强势；跌破中轨 = 趋势转弱 | 突破上轨不是卖点 |
| **均线（MA5/10/20）** | 核心工具：MA5 是短线生命线，跌破即离场 | 无 |
| **分时均价线** | **最重要的实时指标**，跌破即卖 | 无 |
| **筹码分布 CYQ** | 判断上方套牢压力与主力换手 | 部分软件算法不同，只看趋势不看绝对值 |

**一条经验：** 如果你需要靠指标来说服自己买入，说明这只票的量能和分时不够强。**真正的强势票，看一眼分时和成交量就够了。**

# 9. 十条不可违反的纪律

1. **退潮期空仓。** 没有例外。
2. **10:30 前必走**，除非 5.3 🟢 的 A/B/C 三组全部满足。
3. **止损价一旦挂出，永不上调。**
4. 单日亏损达总资金 2%，**当日停手**。
5. **不买不是板块前三的票。**
6. **不买头上 8% 内有天量套牢区的票。**
7. **不补仓、不摊薄成本。** 隔日短线没有补仓这个动作。
8. **不做没有量的票**（成交额 < 8亿一律不看）。
9. **每笔交易买入前写下理由**，写不出来就不买。
10. **连亏三日强制空仓一天。**

# 11. 上手节奏建议

**这套体系不要一上来就用真金白银全额执行。**

| 阶段 | 时长 | 做什么 |
|---|---|---|
| 第 1 阶段 | 2 周 | **纯模拟**。每天按 3.7 流程选股、按 3.8 打分、次日按 5.3 判定，只记录不下单。目标：验证你的选股胜率 |
| 第 2 阶段 | 4 周 | 用短线仓的 **1/4**（总资金 5–10%）实盘。目标：验证你能否执行纪律 |
| 第 3 阶段 | 持续 | 按第 1 章规则全额执行。每月回顾，用自己的数据修正阈值 |

**判断能否进入下一阶段的标准（用你自己的数据，不是感觉）：**
- 胜率 ≥ 55%，且
- 平均盈利 / 平均亏损 ≥ 1.5，且
- **纪律执行率 ≥ 90%**（复盘表里"是否按规则执行"为"是"的比例）

第三条不达标就不要加仓位——**在纪律不稳的阶段放大资金，是亏钱最快的方式。**

## 附：本手册的核心逻辑回顾

```
   能不能做？        →  第 2 章（情绪周期，不过关就空仓）
        ↓
   做哪一只？        →  第 3 章（五维共振 + 打分卡 ≥ 75）
        ↓
   什么时候买？      →  第 4 章（尾盘定档 14:50）
        ↓
   明天怎么办？      →  第 5 章（竞价定性 → 均价线执行 → 10:30 硬闹钟）
        ↓
   怎么变强？        →  第 8 章（复盘归类，每个错误变成一条规则）
```

**最后一句：**
这套体系的真正价值不在于让你抓到多少涨停，而在于**让你在不该做的日子里不做**。隔日超短的长期收益，主要来自避免退潮期的连续亏损，而不是来自主升期多赚的那几个点。
