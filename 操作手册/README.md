# 股票技术分析系统

包含两大核心功能：
1. **个股技术分析报告生成** - 深度分析单只股票
2. **每日短线选股系统** - 自动筛选符合条件的短线机会

## 📋 功能特点

### 功能一：个股技术分析报告

✅ **全自动数据获取**
- 实时行情数据（最新价、涨跌幅、成交量、换手率等）
- 历史K线数据（近10个交易日完整数据）
- 自动计算技术指标

✅ **完整技术指标分析**
- **均线系统**：MA5、MA10、MA20、MA60
- **MACD指标**：金叉/死叉自动识别
- **KDJ指标**：超买/超卖判断
- **RSI指标**：强弱区域分析
- **布林带**：BOLL上中下轨分析

✅ **智能分析建议**
- 综合技术评分（50分制）
- 多空力量对比
- 支撑位和压力位识别
- 短线和中线操作建议
- 风险提示

### 功能二：每日短线选股系统

✅ **智能筛选条件**
- 换手率 > 15%（市场活跃）
- 涨幅 1-3%（适度上涨）
- 量能明显放量（比前2日平均 > 1.5倍）
- KDJ < 80（未超买）
- RSI < 70（未超买）

✅ **综合评分排序**
- 多维度评分系统
- Top 20 精选推荐
- Top 5 详细分析

✅ **详细操作建议**
- 买入时机建议
- 仓位管理策略
- 止损止盈位设置

## 🚀 快速开始

### 环境要求

- Python 3.11
- 依赖库：requests、pandas、numpy

### 安装依赖

```bash
py -3.11 -m pip install requests pandas numpy
```

### 使用方法

#### 1️⃣ 个股技术分析

```bash
cd E:\trading
py -3.11 stock_report_generator.py
```

然后按提示输入股票代码（如：600664）

#### 2️⃣ 每日短线选股

```bash
cd E:\trading
py -3.11 daily_stock_picker.py
```

**建议执行时间：** 每天 14:50 左右（收盘前10分钟）

**注意：** 选股功能需要访问 `82.push2.eastmoney.com`，如果该API无法访问，功能将不可用。

## 📊 报告内容

生成的报告包含以下内容：

### 一、基本信息
- 股票代码、名称、行业、交易所

### 二、最新行情数据
- 最新价、涨跌幅、成交量、换手率
- 今开、最高、最低、昨收
- 市盈率、市净率、总市值、流通市值

### 三、近10日交易数据
- 完整的价格走势表格
- 成交量、成交额、换手率
- 区间统计（最高价、最低价、涨跌幅等）

### 四、技术指标分析
- 均线系统分析（多头/空头排列）
- MACD指标（金叉/死叉）
- KDJ指标（超买/超卖）
- RSI指标（强弱判断）
- 布林带分析

### 五、成交量分析
- 量能变化趋势
- 量价关系判断
- 换手率水平评估

### 六、综合技术评分
- 趋势强度评分
- 多空力量评分
- 成交活跃度评分
- 技术指标共振评分
- 短期动能评分

### 七、关键价格位
- 强支撑、次支撑、弱支撑
- 强压力、次压力、弱压力

### 八、操作建议
- 短线建议（1-3天）
- 中线建议（1-2周）
- 买入价、止损位、目标位

### 九、风险提示
- 技术风险
- 市场风险

## ⚙️ 技术说明

### 数据来源
- 实时行情：东方财富 `push2.eastmoney.com` API
- 历史数据：东方财富 `push2his.eastmoney.com` API

### 技术指标计算
所有技术指标均采用标准算法计算：
- **均线**：简单移动平均
- **MACD**：EMA(12) - EMA(26)
- **KDJ**：9日RSV平滑
- **RSI**：相对强弱指数
- **BOLL**：20日均线 ± 2倍标准差
